# 无客户端播放：研究结论与正式实现

2026-10-30 的预研确认：用户账号可通过 api-enhanced `song_url_v1` 获取有权播放的普通音源，再由独立播放器获取和解码，不需要网易云桌面客户端。

**该路径现已成为 0.2.0 正式 MCP 的默认实现。** 当前操作和验收以 README、MCP 工具说明及本机验收记录为准；原先“正式工具仍控制桌面客户端”的阶段性说明已失效。

## 预研证据

- 实际 API 版本 4.36.1，固定提交 `b7bf2b527c5c0b2e67515f1573a4aa40f3b556fa`
- 当前账号会员状态有效，曲目 316157：standard 返回 MP3 128 kbit/s，exhigh 返回 MP3 320 kbit/s
- 无试听标记，服务端时长约 308773 ms，当次源有效期 1200 秒
- HTTPS Range 获取约 1.51 MB 音频，本机 ffmpeg 内存解码出 36 秒 PCM，未调用桌面客户端
- 后续正式 mpv 后端已通过全部 20 个 MCP 工具实测，包括超过 32 秒真实播放

预研摘要保留在忽略的 `evidence/direct-playback-research.json`，历史研究脚本与原文位于 `.data/history/0.1.0/`；它们不是正式启动入口。正式复验使用 `npm run verify`。

## 接口与协议选项

上游为 [NeteaseCloudMusicApiEnhanced/api-enhanced](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced)。本项目固定源码参考：[song_url_v1](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced/blob/b7bf2b527c5c0b2e67515f1573a4aa40f3b556fa/module/song_url_v1.js)。

预研默认 xeapi 因缺少初始化公钥失败；使用库支持的 `crypto: 'eapi'` 后正常返回。该选项是请求协议选择，不是音频保护解密。正式实现明确关闭 `unblock`，不调用替代音源、会员解锁或 DRM 解密。

## 对小车的意义

可以在小车桥接的数据层复用账号和授权解析，将音频送到板端，并依据真实播放位置同步歌词与频谱。如此无需捕获桌面网易云声音，也不必为了音乐临时切换系统主输出设备。这是后续设计路径；当前正式项目仍由 mpv 向电脑输出，没有完成 ESP32 输出适配。
