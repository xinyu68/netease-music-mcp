## 源码包安装检查

已将不含依赖和二进制的源码包解压到独立空目录，通过 `npm ci --ignore-scripts` 安装 281 个包、运行离线检查，并从微软 NuGet 重新下载 WebView2 SDK、验证三个 DLL 的哈希、编译登录窗口成功。说明安装不依赖原项目的 node_modules 或已有 WebView2 SDK 文件。后续补充的 IPC 取消回归使最终离线测试达到 30 项，全部通过。

最终依赖地址已明确使用 HTTPS 加固定 Git 提交，避免迁移时依赖个人 GitHub SSH 密钥；lockfile 一致性 dry-run 检查通过。源码包清单包含 lockfile，不含本机配置、凭据、node_modules、mpv 和登录窗口二进制。Windows mpv 的固定压缩包下载、哈希和解包另已在本机验证。
