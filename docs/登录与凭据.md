# 登录与凭据

## 正常使用

新用户运行 `node scripts/setup.mjs`（独立 MCP）或 `node scripts/setup.mjs --plugin`（插件）。命令会准备依赖并完成登录检查。已有会话先通过网易云账号接口验证；有效就直接返回。只有需要登录时才打开官方网页登录窗口，账号、二维码或验证码由用户本人操作。取消会停止，不删除原会话，也不自动退出账号。开发者也可在已安装依赖后单独执行 npm run login。

登录窗口源码在 `vendor/login/windows/WebViewLogin.cs` 和 `vendor/login/macos/LoginWindow.swift`。Windows 通过 WebView2，Mac 通过 WKWebView，完成后只提取 `MUSIC_U` 和 `__csrf`。浏览器资料目录与会话目录归本项目所有，不依赖桌面网易云的登录状态。

## 保存位置与保护

| 平台 | 默认状态目录 | 会话保护 |
| --- | --- | --- |
| Windows | `%LOCALAPPDATA%\netease-music-mcp` | 当前用户 DPAPI 加密；换电脑/用户不能直接解密 |
| Mac/Linux | `~/.local/state/netease-music-mcp` | Base64、0600 权限；不是加密存储 |

会话文件名为 `session.dpapi`。非 Windows 保留同名只是格式兼容，不表示使用 DPAPI。不要将状态目录加入 Git、交接包或聊天。若需更强的 Mac 凭据保护，可后续接入 Keychain；当前未实现。

Windows 解密仅发生在受控子进程内，密文走 stdin，明文 stdout 由父进程在内存接收，不转发给 MCP、日志或聊天。API 请求使用 Cookie；独立 CDN 音频请求不带 Cookie。播放器通过私有命名管道/Unix socket接收临时 URL，不把它放在命令行。

自检 `npm run doctor -- --online` 同时验证播放器与会话，不播放声音。它区分“本地文件存在”和“在线账号验证成功”；单纯看到文件不等于登录成功。

## 可选：兼容已有的加密会话

如果你以前在同一 Windows 用户下使用过兼容的网易云上传工具，可以**独占复制**自己已有的加密会话；这是可选迁移方式，普通用户直接官方网页登录即可。原文件不会被修改，日常运行不依赖原工具。不要导入他人的凭据。

可选命令（仅同一 Windows 用户/电脑、且目标会话文件尚不存在时使用）：

```powershell
npm run auth:import
# 或显式指定已有加密文件
npm run auth:import -- "C:\path\to\session.dpapi"
```

已有目标文件时导入会失败，避免覆盖。导入后验证失败也不会删除原始文件。不要将 Windows 密文拷到 Mac 作为迁移方案，在 Mac 重新登录。

## 构建和失败处理

Windows `npm run build:login` 使用系统 .NET Framework C# 编译器和固定 WebView2 SDK。下载与 DLL 哈希见 `tools/webview2-manifest.json`；WebView2 Runtime 由系统另外安装。`--probe` 只检查 Runtime，不打开窗口。

Mac 需 Xcode Command Line Tools，`npm run build:login` 调用 `swiftc` 编译，不包含预编译 Mac 程序。Mac helper 尚未实机验证。

窗口退出码：0 完成，10 浏览器运行时初始化失败，11 用户取消，12 页面导航失败，13 读取/保存会话失败。程序不会在失败时尝试未经验证的备用登录或偷偷删除凭据。本轮已验证 Windows 编译、Runtime 探测、加密会话读取及账号验证；没有强制使现有会话失效来重新扫码，所以不能声称本轮重新验收了交互式扫码全流程。
